# FAQ

## What is Magdi-AI?

Magdi-AI is a QA activity workflow system designed to support QA professionals of all levels.

## Alpha?

Magdi-AI 4 is an evolution from Magdi-AI 3.  Alpha gives us an opportunity to present some of the ideas we imagined to provide an opportunity to try them out and offer critique as well as suggestons we can consider to further expand the concept.

## Offline?

Presently, Ollama provides an offline solution to using AI after downloading and installing Ollama.  Future releases will include a Magdi-LLM and models that will allow for offline use.

## OpenAI?

We offer to choose OpenAI if that is your AI of choice.

## Ollama?

An opensource AI one can use offline.

## Integrations?

Integrations to popular platforms like Jira, MicroSoft Azure, Sharepoint or GitHub is planned.  The first workflow  we wish to support in Magdi-AI is

 Jira -> Magdi-AI -> Magdi-AI Executes Tasks -> Magdi-AI produces Artifacts -> GitHub / TestRail
