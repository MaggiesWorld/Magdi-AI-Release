# Magdi-AI REL 4 Alpha

Welcome to Magdi-AI.

Magdi-AI is an AI-powered Quality Assurance Platform that helps QA professionals plan, organize, and automate software testing through guided workflows and AI-assisted capabilities.

## Current Features

- AI-powered onboarding
- Project and Work Item management
- Quality Workflow Engine (QWE)
- AI-generated QA artifacts
- Resource management
- Multiple LLM providers
    - OpenAI
    - Anthropic Claude
- KPI Dashboard
- Activity Feed

## Known Issues

### Duplicating Work Items

If you add a work item and click ready before saving, the item will save and duplicate.

Work Around
1.  Click '+' to Add Work Item
2.  Click Save
3.  When ready, Click Work Item
4.  Click 'Ready'

The QWE will take it from there and alert you when the item is ready for review.


### Workflows

Currently, only Kanban-QA is supported.  The other workflows will be available after the beta release.
